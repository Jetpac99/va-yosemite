# VA Yosemite EDS Page

Minimal Adobe Edge Delivery Services repo for the Yosemite hiking trails static page.

## Page

- `/yosemite.html` contains the authored page content.
- `/assets/yosemite/` contains only the page imagery.
- `/fonts/` contains the Gotham font files used by the Virgin Atlantic style layer.
- `/styles/styles.css` contains the portable Virgin Atlantic static page CSS.
- `/scripts/scripts.js` contains only progressive enhancements for carousel controls and tabs.

The page content is plain HTML so it can be edited in AEM/DA rather than being generated by a client-side app.
